# AzureADScriptsIAC
Set of scripts for integrating Azure AD with our on prem AD in MARS DC


## Required tools

__AzureAD module__ - Azure AD powershell modules. read more here: [MS Docs](https://learn.microsoft.com/en-us/powershell/module/azuread/?view=azureadps-2.0)

__Windows RSAT tools__ - Connect to MARS AD from local computer.
[Download here](https://www.microsoft.com/en-us/download/details.aspx?id=45520)
